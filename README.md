# 美食佳的知识库

每个栏目一页，不在一页中呈现全部栏目。首页 `index.html` 只做栏目导航，不呈现各栏目的具体内容。

锚点定位统一处理：所有带 id 的目标都有 90px 的顶部留白，不会被粘性顶栏遮挡；微信类别在 JS 渲染完成后会再按地址栏锚点滚动一次；招聘页从搜索或外部链接带 #job- 进来时，会先切换到对应日期 Tab 再滚动到该岗位；切换日期 Tab 时会滚动到 Tab 位置。

## 导航

导航顺序为微信畅谈、个股成长、招聘打野、数据导航、新闻聚合（新闻聚合最后，新闻聚合为外部跳转，无本站内新闻页），不设首页；根地址直接跳转到微信畅谈。栏目页不设顶部编号和大标题。微信畅谈与个股成长页最前面有类别链接，点击直接进入对应位置；每页右下角都有一个小圆钮（仅红色 ↑），点击用 JS 直达页首。

## 设计

全站为米色点纹底、细边圆角区格卡片、砖红点缀：暖米色底加细密圆点纹，卡片为近白米色细边圆角，章节编号与点缀用砖红，涨跌仍用 ▲▼ 符号表示，不用红绿。每个栏目页顶部都有全局搜索框，搜标题与简介，点结果进对应页面；搜索索引只含本站已公开的内容。

## 页面

- `index.html`：直接跳转到微信畅谈，本站不设单独首页。
- `wechat.html`：微信畅谈，自动归类（持仓与个股、生活兴趣、其他），按条数从多到少动态排序，只展示最近 2 个对话，其余折叠，点击展开后查看；每条对话同时展示微信问题与 Muse 回答，持仓类完整回答中的资产金额已隐去，图片内容不在本页展示。
- `stocks.html`：个股成长，每只个股顶部为收盘、涨跌、MA20、MA60、RSI、动作 6 格小统计；下面按日期分行，每行左右配对（左边盘前报告、右边收盘报告，同一天横向比较），盘前与收盘格内均为标签配数值的行加虚线分隔，另有 20 日位置条（20 日位置由该股 20 日高低与收盘算出）；每格先列核心数据（开盘 10-27、MA5 / MA20 / MA60、估值、主力资金动作），配对行下方单独成区列红方、蓝方、中立裁判三栏（以行业、政策、新闻、基本面为主，技术只作支撑；新闻以已核实的标题为准，正文未读的不展开，暂无信息的如实标注）；目前日期为 2026-10-28（盘前已有，收盘待 15:30 后生成）与 2026-10-27（盘前暂无未收录，收盘只有云铝有框架日报 v4）；开盘与 MA5 除云铝（PanWatch 日线，开盘 25.34 元，MA5 25.23 元）外暂无可靠口径，未编造；已卖出个股统一放在最后的已卖出区，历史不删，买回后按市值移回持仓区（目前 0 只已卖出）；只展示公开行情与技术指标，不展示资产金额；不构成投资建议。
- `jobs.html`：招聘打野，每张卡片标明来源平台（智联招聘 / 51job）并附详情链接，点去投递直接打开该岗位的可投递页面（6 条详情链接均于 2026-10-27 经浏览器打开验证，公司、岗位、薪资、地点、发布日期一致；旭载要求按详情页为大专、1-3 年），按发布日期 Tab 切换，按日期呈现推荐职位；另有“已投递”Tab，按投递时间从近到远呈现本页标记为已投递的岗位，展示最近 5 个，其余折叠；每张卡片显示是否投递、投递时间（本地记录）和反馈状态；已投递过的岗位已剔除，不再推荐。
- 新闻聚合：不设本站内新闻页，导航里的新闻聚合直接跳转外部实时页（新窗口打开）。
- `datanav.html`：数据导航，5 组 20 张直达卡（ETF Monitor 2 张、集思录可转债 3 张、场内基金 5 张、打新与债券 4 张、工具与比价 6 张），本站不抓取数据，只做分类导航，点击卡片直接打开对应第三方数据页，内容仅作方法研究，不构成投资建议。

## 设计参考

栏目编号、时间倒序、最新展开其余折叠的呈现方式；本站的品牌、文案与数据均为原创或已核实的真实内容。

## 投递说明

本页是静态看板，投递按钮本身不直接向招聘方提交申请。点“去投递”会打开岗位的招聘平台页面（51job 岗位有直接链接，智联岗位请在智联搜索公司名 + 岗位名），在平台完成投递后点“我已在平台投递”，本页会在你自己的浏览器里记下投递时间；反馈也是同样在本页本地记录。
