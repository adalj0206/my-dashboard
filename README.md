# 美食佳的知识库

已取消首页大标题区，直接呈现栏目，无示例、无模拟。栏目为微信畅谈、个股成长、招聘打野、新闻聚合、数据导航。

## 五个栏目

- 微信畅谈：按时间从近到远排序，只展示最近 3 个对话，其余折叠，点击展开后查看。来源：2026-10-27 当天经微信桥接收到的任务，内部标识、凭证和图片内容不在本页展示。
- 个股成长：按个股呈现，数据来源于个股日报与持仓股盘前报告（2026-10-28，数据截至 2026-10-27 收盘），只展示公开行情与技术指标，不展示资产金额；不构成投资建议。
- 招聘打野：按发布日期 Tab 切换，按日期呈现推荐职位；每张卡片显示是否投递、投递时间（本地记录）和反馈状态；已投递过的岗位已剔除，不再推荐。
- 新闻聚合：参照 NewsNow 关注页版式，一排展示 3 个；新闻为 2026-10-27 晚间抓取的静态快照，更新需重新部署。
- 数据导航：参照超级鹿鼎公学习站的数据导航页（https://ludinggong-study.pages.dev/data-nav），本站不抓取数据，只做分类导航，点击卡片打开参考站数据导航页，再从那里直达对应实时数据页面；内容仅作方法研究，不构成投资建议。

## 投递说明

本页是静态看板，投递按钮本身不直接向招聘方提交申请。点“去投递”会打开岗位的招聘平台页面（51job 岗位有直接链接，智联岗位请在智联搜索公司名 + 岗位名），在平台完成投递后点“我已在平台投递”，本页会在你自己的浏览器里记下投递时间；反馈也是同样在本页本地记录。
