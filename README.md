# 美食佳的知识库

每个栏目一页，不在一页中呈现全部栏目。首页 `index.html` 只做栏目导航，不呈现各栏目的具体内容。

## 页面

- `index.html`：栏目导航，链接到下面 5 页。
- `wechat.html`：微信畅谈，自动归类（持仓与个股、生活兴趣、其他），每个类别按时间从近到远排序，只展示最近 2 个对话，其余折叠，点击展开后查看；每条对话同时展示微信问题与 Muse 回答，持仓类完整回答中的资产金额已隐去，图片内容不在本页展示。
- `stocks.html`：个股成长，按个股呈现，数据来源于个股日报与持仓股盘前报告，只展示公开行情与技术指标，不展示资产金额；不构成投资建议。
- `jobs.html`：招聘打野，按发布日期 Tab 切换，按日期呈现推荐职位；另有“已投递”Tab，按投递时间从近到远呈现本页标记为已投递的岗位，展示最近 5 个，其余折叠；每张卡片显示是否投递、投递时间（本地记录）和反馈状态；已投递过的岗位已剔除，不再推荐。
- `news.html`：新闻聚合，参照 NewsNow 关注页版式，一排展示 3 个；新闻为静态快照，更新需重新部署。
- `datanav.html`：数据导航，参照超级鹿鼎公学习站的数据导航页（https://ludinggong-study.pages.dev/data-nav），本站不抓取数据，只做分类导航，点击卡片打开参考站数据导航页，再从那里直达对应实时数据页面；内容仅作方法研究，不构成投资建议。

## 设计参考

栏目编号、时间倒序、最新展开其余折叠的呈现方式，参照超级鹿鼎公学习站的结构；本站的品牌、文案与数据均为原创或已核实的真实内容，没有复制对方的内容。

## 投递说明

本页是静态看板，投递按钮本身不直接向招聘方提交申请。点“去投递”会打开岗位的招聘平台页面（51job 岗位有直接链接，智联岗位请在智联搜索公司名 + 岗位名），在平台完成投递后点“我已在平台投递”，本页会在你自己的浏览器里记下投递时间；反馈也是同样在本页本地记录。
