# 美食佳的知识库

专属沟通知识库网站，版式参考知识库网站的**标题区、索引卡、TOP 榜、问答区、图谱区**结构，但品牌、文案、数据均为本站原创示例，没有复制对方内容。

三个栏目：微信沟通（暂无真实记录，仍为示例）、个股沟通（此前讨论过的话题快照，非实时、不是持仓）、招聘沟通（已核实的公开岗位，全部未投递，已投递过的岗位已剔除），每个栏目都有榜单和近期记录，顶部还有一个按关键词在本页记录里查找的沟通助手。

## 本地预览

直接用浏览器打开 `index.html` 即可，无需构建、无需后端。

功能：顶部搜索过滤、栏目切换、沟通助手关键词查找；每个栏目下近期记录默认只展示最近 3 条，其余点击展开，点击单条记录可查看明细。

## 换成你自己的数据

打开 `index.html`，改底部 `DATA` 里三组数组：

- `wechat`：微信沟通的 TOP 榜和近期记录（示例）
- `stocks`：个股话题的榜单和近期记录（此前讨论快照，非实时、不是持仓）
- `jobs`：已核实岗位的榜单和近期记录（公开岗位，未投递；已投递过的岗位不要重新列入）

每条记录填日期、对象、标题、内容、主题标签和状态即可。

## 上线：GitHub + Cloudflare Pages

1. GitHub 仓库：`adalj0206/my-dashboard`，公开。

3. 当前部署方式是 Wrangler 直接上传，不是 Git 连接项目：改完 `index.html` 后要重新跑一次 Wrangler 部署，GitHub 提交本身不会自动上线。

## 注意

- 这是纯静态站，没有登录和后端数据库。
- 不要把真实微信记录、私人数据、真实持仓或 API Key 直接写进公开仓库；公开仓库和 Pages 地址任何人打开都能看到，个股内容也不构成投资建议。
- 如需接真实数据，下一步可以改成：数据放在私有接口里，前端用 fetch 读取；或用 Cloudflare Workers 做一层鉴权后再返回数据。
